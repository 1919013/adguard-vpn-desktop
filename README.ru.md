# ADGuard VPN Desktop

Независимая графическая оболочка сообщества для официального AdGuard VPN CLI в Linux. Проект не является продуктом AdGuard и не связан с AdGuard Software Ltd.

> Проект находится в разработке. Это независимая графическая оболочка для официального AdGuard VPN CLI, а не продукт AdGuard.

## Цели
- Подключение и отключение AdGuard VPN CLI.
- Просмотр списка VPN-серверов и выбор локации.
- Проверенная маршрутизация отдельных приложений через VPN (split tunneling).
- Управление DNS с резервным копированием и проверками утечек.
- Диагностика, настройки и контекстная справка.
- Поддержка русского и английского языков.

## Архитектура
- `core/` — основная логика и координация.
- `modules/` — пользовательские функции.
- `services/` — DNS, резервное копирование и NetworkManager.
- `ui/` — GTK-интерфейс.
- `i18n/` — переводы.
- `docs/` — документация.
- `tests/` — автоматические тесты.

Интерфейс не должен запускать системные команды напрямую.

## Безопасность
- Не менять активные профили NetworkManager без явного согласия пользователя.
- Перед изменением DNS необходимы проверенная резервная копия и проверенный откат.
- Сначала разрабатывать DNS на отдельном тестовом профиле.
- Не объявлять split tunneling готовым до проверки маршрутизации, DNS и IPv6.
- Не добавлять в Git учётные данные, ключи и локальные DNS-снимки.

## Состояние
Подключение, список серверов, динамическое обнаружение NetworkManager, привязка VPN CLI к одному интерфейсу, обслуживание CLI, диагностика, автозагрузка GUI и HTML-справка реализуются. Маршрутизация отдельных приложений и полноценное управление рабочими DNS-профилями пока не реализованы.
