# ADGuard VPN Desktop

Независимая графическая оболочка для **AdGuard VPN CLI** в Linux. Проект не разработан, не одобрен и не поддерживается компанией AdGuard.

> Состояние: ветка разработки проходит проверку. Проверка работы на целевых настольных системах и подготовка пакетов ещё не завершены.

## Реализованные функции в текущей ветке

- Подключение и отключение AdGuard VPN CLI, просмотр и выбор VPN-серверов.
- Вкладка управления AdGuard VPN CLI: обнаружение установки, официальный сценарий установки и обновления, состояние, подключение/отключение, очистка кэша и пользовательских данных, отдельное управление автозапуском CLI и графической оболочки.
- Динамическое обнаружение сетевых интерфейсов и настройка исходящего интерфейса AdGuard VPN CLI. Список устройств определяется во время работы; имена личных профилей NetworkManager не зашиты в код. Сам CLI поддерживает выбор одного исходящего интерфейса.
- Вкладка исключений сайтов, использующая штатные списки AdGuard VPN CLI в режимах General и Selective.
- Отдельные ярлыки запуска приложений через SOCKS5 AdGuard VPN CLI и `proxychains4` (ограниченный вспомогательный механизм).
- Добавлен экспериментальный планировщик маршрутизации выбранных приложений через TUN на основе cgroup v2, systemd и nftables. Пока это только проверяемая основа: она не подключена к кнопке применения и не меняет сетевые настройки.
- Интерактивная справка, открываемая в браузере, с явным указанием на независимый статус проекта.
- Вкладка DNS в намеренно ограниченном тестовом режиме.

## Раздельное туннелирование

### Сайты

Вкладка «Исключения сайтов» управляет штатной функцией CLI:
- **General** — перечисленные сайты идут напрямую, вне VPN.
- **Selective** — через VPN идут только перечисленные сайты.

Списки двух режимов независимы от выбора приложений. Официальная документация: [Настройки AdGuard VPN для Linux](https://adguard-vpn.com/kb/ru/adguard-vpn-for-linux/settings/).

### Приложения

Текущие ярлыки через SOCKS5/прокси не являются полноценным split tunneling: перехват не гарантирован для каждого протокола и приложения. Для нативной маршрутизации TUN добавлена экспериментальная основа с выделенной systemd-группой, nftables socket-cgroup matching и отдельной таблицей маршрутов. Пока реализован планировщик и headless-тесты; интеграция с UI, сценариями подключения/отключения и режимом «все приложения, кроме выбранных» ещё не завершена. Не используйте экспериментальные правила вручную на рабочем подключении до отдельной проверки.

## DNS

Текущий менеджер DNS — тестовый механизм безопасности, ограниченный двумя явно разрешёнными тестовыми профилями. Он отказывается изменять активные тестовые профили и выполнять запись, если не подтверждено состояние AdGuard VPN TUN. Обычные пользовательские профили NetworkManager не изменяются. Это ещё не промышленная система управления DNS и не проверка утечек DNS.

## Сетевые интерфейсы

Вкладка динамически обнаруживает существующие нетуннельные интерфейсы, кроме loopback, и применяет документированную настройку `adguardvpn-cli config set-bound-if-override`. Профили NetworkManager не редактируются. Параметр CLI принимает один интерфейс; сброс выбора возвращает автоматический выбор интерфейса.

## Разработка и проверки

Активная ветка разработки — `feature/large-feature-blocks`; см. [pull request №2](https://github.com/1919013/adguard-vpn-desktop/pull/2).

Локальные проверки:

```sh
python -m compileall -q core modules services ui main.py
python -m unittest discover -s tests -v
```

GitHub Actions выполняет эти проверки при отправке изменений и открытии pull request. Успешный CI не заменяет проверку работы на Debian/Cinnamon.

## Структура проекта

- `core/` — основная логика приложения.
- `modules/` — вкладки и контроллеры функций.
- `services/` — интеграция с системой и работа с состоянием.
- `ui/` — интерфейс GTK.
- `i18n/` — запланированные переводы.
- `tests/` — регрессионные тесты без GUI.

## Обновление текущей Git-копии

Для чистой копии репозитория с настроенной upstream-веткой:

```sh
git pull --ff-only
```

Для пользовательской установки, создаваемой графической оболочкой:

```sh
cd ~/.local/share/adguard-vpn-desktop/app && git pull --ff-only
```
