# ADGuard VPN Desktop

Открытая графическая оболочка GTK для **AdGuard VPN CLI** в Linux. Это сторонний общественный GUI-wrapper, а не официальное настольное приложение AdGuard; проект не связан с AdGuard.

## Что реализовано сейчас

- Подключение и отключение AdGuard VPN CLI, получение статуса и выбор VPN-локации.
- Чтение списка сетевых интерфейсов, IP-адресов и состояния устройств NetworkManager без изменения настроек.
- Информационная строка показывает туннельный интерфейс, который сообщает AdGuard VPN CLI (например, `tun0`).
- Экспериментальная вкладка DNS с проверкой резервной копии и ограничением операций явно разрешёнными тестовыми профилями.

## Что ещё не реализовано или не проверено

- Раздельное туннелирование приложений. Вкладка «Приложения» пока остаётся заглушкой; трафик приложений этой программой не маршрутизируется.
- Применение выбранных сетевых интерфейсов к маршрутизации. Вкладка интерфейсов пока только обнаруживает и показывает устройства; флажки выбора временные.
- Универсальное управление DNS для произвольных профилей NetworkManager пользователя.
- Управление продуктом AdGuard, обновления самой оболочки, полные настройки и справка в браузере.
- Сквозная проверка маршрутизации, утечек DNS и IPv6 на поддерживаемых системах Debian.

## Архитектура

- `core/` — взаимодействие с CLI и основная логика.
- `modules/` — пользовательские функции.
- `services/` — интеграция с операционной системой.
- `ui/` — интерфейс GTK.
- `i18n/` — переводы.
- `docs/` — документация.
- `tests/` — автоматические тесты.

Интерфейс не должен запускать системные команды напрямую. Операции с системой изолированы в слоях core/services.

## Безопасность

- Обнаружение интерфейсов работает только на чтение.
- Изменение DNS ограничено специально разрешёнными тестовыми профилями; рабочие профили не меняются.
- Перед изменением DNS необходимы проверенная резервная копия и проверенный откат.
- Нельзя объявлять раздельное туннелирование готовым до проверки маршрутизации, DNS и IPv6.
- Не добавлять в Git учётные данные, ключи и локальные DNS-снимки.
