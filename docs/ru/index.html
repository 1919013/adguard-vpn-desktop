ADGuard VPN Desktop

Независимая графическая оболочка сообщества для официального AdGuard VPN CLI. Это не продукт AdGuard и не официальный интерфейс AdGuard Software Ltd.

Инфо ADGuard VPN CLI

Показывает наличие исполняемого файла и версию, проверяет обновления встроенной командой CLI. Установка запускает официальный установочный скрипт в отдельном терминале; обновление запускает команду adguardvpn-cli update -v в терминале, чтобы запрос пароля администратора был виден. Подключение и отключение VPN выполняются на вкладке «Подключение». Команды безопасной очистки кэша или всех пользовательских данных не подтверждены; поэтому такие операции не предлагаются.

Подключение

Вкладка «Подключение» показывает состояние CLI, список локаций и управляет подключением/отключением через adguardvpn-cli.

Сетевые интерфейсы

Устройства и профили NetworkManager обнаруживаются динамически. AdGuard VPN CLI позволяет привязать исходящий VPN-трафик к одному интерфейсу командой config set-bound-if-override. Это не изменяет профиль NetworkManager. Сброс привязки возвращает автоматический выбор интерфейса. Одновременный выбор нескольких интерфейсов CLI не предоставляет.

Приложения и split tunneling

Настоящая маршрутизация отдельных приложений пока не реализована. Доменные исключения CLI не являются маршрутизацией приложений. Официальный CLI предоставляет режим пользовательского скрипта маршрутизации туннеля SCRIPT; его поведение при подключении, отключении и переподключении ещё проверяется. До проверки системного механизма и DNS, IPv4, IPv6, дочерних процессов и отката переключатели маршрутизации приложений не показываются. Технические заметки о маршрутизации и DNS.

DNS и защита

Внимание: текущий DNS-модуль ограничен специальными тестовыми профилями NetworkManager. Не используйте его для рабочих профилей. Официальный CLI также имеет собственные команды настройки DNS; интеграция через CLI исследуется как предпочтительный вариант. Безопасный сброс upstream к исходному значению должен быть подтверждён до реализации. Чтение DNS-настроек не является полноценным тестом утечек.

Настройки

Можно отдельно включить автозагрузку графической оболочки и автоподключение AdGuard VPN CLI. Для CLI создаётся пользовательская запись XDG Autostart с командой adguardvpn-cli connect -y --boot. Перед созданием приложение проверяет, что установленная версия CLI показывает поддержку --boot. Это запускается при входе в графический сеанс, не является системной службой systemd и требует установленного CLI и авторизованной учётной записи. Отключение удаляет только запись автозагрузки.

Диагностика

Диагностика читает состояние CLI, устройства NetworkManager, IP-адреса интерфейсов, маршруты IPv4/IPv6 по умолчанию, результаты локального выбора маршрута до тестовых IPv4/IPv6-адресов и DNS, настроенные в NetworkManager. Сетевые параметры не меняются. Это не полноценная проверка DNS/IPv4/IPv6-утечек.

Безопасность

  • Не удаляйте пользовательские данные CLI без резервной копии и подтверждения.
  • Не применяйте DNS или маршруты к активным профилям без плана отката.
  • Предупреждение CLI о системном DNS означает, что защита DNS не подтверждена.
