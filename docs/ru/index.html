ADGuard VPN Desktop

Независимая графическая оболочка сообщества для официального AdGuard VPN CLI. Это не продукт AdGuard и не официальный интерфейс AdGuard Software Ltd.

Подключение

Вкладка «Подключение» показывает состояние CLI, список локаций и управляет подключением/отключением через adguardvpn-cli.

Сетевые интерфейсы

Устройства и профили NetworkManager обнаруживаются динамически. AdGuard VPN CLI позволяет привязать исходящий VPN-трафик к одному интерфейсу командой config set-bound-if-override. Это не изменяет профиль NetworkManager. Сброс привязки возвращает автоматический выбор интерфейса. Одновременный выбор нескольких интерфейсов CLI не предоставляет.

Приложения и split tunneling

Настоящая маршрутизация отдельных приложений пока не реализована. Доменные исключения CLI не являются маршрутизацией приложений. Для полноценной реализации необходим системный механизм и проверка DNS, IPv4, IPv6, дочерних процессов и отката.

DNS и защита

Внимание: текущий DNS-модуль ограничен специальными тестовыми профилями NetworkManager. Не используйте его для рабочих профилей. Чтение DNS-настроек не является полноценным тестом утечек.

Настройки

Автозагрузка относится только к графической оболочке и использует пользовательский XDG Autostart. Она не создаёт службу VPN и не подключает VPN автоматически.

Диагностика

Диагностика читает состояние CLI и NetworkManager, не изменяя сеть. Это не полноценная проверка DNS/IPv4/IPv6-утечек.

Безопасность

  • Не удаляйте пользовательские данные CLI без резервной копии и подтверждения.
  • Не применяйте DNS или маршруты к активным профилям без плана отката.
  • Предупреждение CLI о системном DNS означает, что защита DNS не подтверждена.
