ADGuard VPN Desktop — справка

ADGuard VPN Desktop — сторонняя графическая оболочка для AdGuard VPN CLI в Linux. Это не официальное настольное приложение AdGuard; проект не связан с AdGuard.

Подключение

Показывает состояние AdGuard VPN CLI, позволяет загрузить список локаций, подключиться к выбранному серверу и отключиться. Предупреждение CLI о невозможности настроить системный DNS означает, что DNS-запросы могут обходить VPN.

Приложения

Выберите приложение из каталога или добавьте исполняемый файл по полному пути. Для защищённого запуска программа проверяет TUN, маршруты и DNS. Кнопка «Прекратить работу через VPN» удаляет правила маршрутизации выбранного приложения, не завершая само приложение. Если VPN отключается аварийно во время защищённого сеанса, приложение может быть остановлено для предотвращения утечки.

Важно. Раздельное туннелирование пока имеет ограничения: один защищённый процесс за раз; уже запущенные экземпляры и D-Bus activation не поддерживаются. Не считайте функцию проверенной на конкретной системе до испытаний.

DNS и защита

Вкладка отображает статус VPN TUN и тестовых профилей NetworkManager. Если тестовый профиль отсутствует, это нормальное состояние: программа должна сообщить, что профиль ещё не создан. Изменения ограничены разрешёнными тестовыми профилями; рабочие Ethernet/Wi‑Fi профили не должны изменяться.

Чтение конфигурации DNS не является полноценным DNS leak test. Для проверки утечек необходим отдельный сетевой тест.

Сетевые интерфейсы

Показывает обнаруженные интерфейсы и сообщает, через какой TUN-интерфейс работает AdGuard VPN. Само обнаружение не изменяет маршруты.

Помощь и диагностика

Длинные сообщения об ошибках можно прокручивать и выделять для копирования. Если операция не выполнена, ориентируйтесь на полный текст ошибки; не повторяйте системные изменения вслепую.

Безопасность

  • Не публикуйте пароли, токены, приватные ключи и персональные сетевые снимки.
  • Не отключайте VPN, пока защищённое приложение использует VPN-маршрутизацию.
  • Если проверка маршрутов или DNS не пройдена, безопасный запуск должен быть запрещён.
