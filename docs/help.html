ADGuard VPN Desktop — справка

ADGuard VPN Desktop — сторонняя графическая оболочка для AdGuard VPN CLI в Linux. Это не официальное настольное приложение AdGuard; проект не связан с AdGuard.

Подключение

Показывает состояние AdGuard VPN CLI, позволяет загрузить список локаций, подключиться к выбранному серверу и отключиться. Предупреждение CLI о невозможности настроить системный DNS означает, что DNS-запросы могут обходить VPN.

Приложения

Выберите приложение из каталога или добавьте исполняемый файл по полному пути. Для защищённого запуска программа проверяет TUN, маршруты и DNS. Кнопка «Прекратить работу через VPN» удаляет правила маршрутизации выбранного приложения, не завершая само приложение.

Важно. Раздельное туннелирование имеет ограничения: один защищённый процесс за раз; уже запущенные экземпляры и D-Bus activation не поддерживаются. Не считайте функцию проверенной на конкретной системе до испытаний.

DNS и защита

Вкладка отображает статус VPN TUN и тестовых профилей NetworkManager. Если тестовый профиль отсутствует, это нормальное состояние: программа сообщает, что профиль ещё не создан. Изменения ограничены разрешёнными тестовыми профилями; рабочие Ethernet/Wi‑Fi профили не должны изменяться.

Чтение конфигурации DNS не является полноценным DNS leak test.

Сетевые интерфейсы

Показывает обнаруженные интерфейсы и сообщает, через какой TUN-интерфейс работает AdGuard VPN.

Диагностика и безопасность

  • Длинные сообщения об ошибках можно прокручивать и выделять для копирования.
  • Не публикуйте пароли, токены, приватные ключи и персональные сетевые снимки.
  • Если проверка маршрутов или DNS не пройдена, безопасный запуск приложения должен быть запрещён.
