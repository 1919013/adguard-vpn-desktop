ADGuard VPN Desktop

Independent community GUI for the official AdGuard VPN CLI. This is not an AdGuard product or an official AdGuard Software Ltd interface.

AdGuard VPN CLI information

This tab checks whether the executable is installed, reads its version and checks for updates using the CLI's built-in command. Installation starts the official installer in a separate terminal; updating runs adguardvpn-cli update -v in a terminal so administrator password prompts remain visible. VPN connect/disconnect is available on the Connection tab. No safe, documented cache or full user-data cleanup procedure has been confirmed, so these destructive actions are not offered.

Connection

The Connection tab reads CLI status and locations and controls connection/disconnection through adguardvpn-cli.

Network interfaces

NetworkManager devices and profiles are discovered dynamically. AdGuard VPN CLI can bind its outbound VPN traffic to one interface with config set-bound-if-override. This does not modify a NetworkManager profile. Clearing the override restores automatic interface selection. The CLI does not provide simultaneous selection of multiple interfaces.

Applications and split tunneling

True per-application routing is not implemented yet. CLI domain exclusions are not per-application routing. A system-level mechanism and verification of DNS, IPv4, IPv6, child processes and rollback are required.

DNS and protection

Warning: the current DNS module is restricted to dedicated test NetworkManager profiles. Do not use it with production profiles. Reading DNS settings is not a complete leak test.

Settings

Autostart applies only to the GUI using the per-user XDG Autostart directory. It does not create a VPN service or connect the VPN automatically.

Diagnostics

Diagnostics read CLI and NetworkManager state without changing the network. They are not a complete DNS/IPv4/IPv6 leak test.

Safety

  • Do not delete CLI user data without a backup and confirmation.
  • Do not apply DNS or routing to active profiles without a rollback plan.
  • A CLI system-DNS warning means DNS protection is unverified.
