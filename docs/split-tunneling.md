# Маршрутизация и исключения AdGuard VPN CLI

## Что поддерживает сам AdGuard VPN CLI

В Linux CLI документирована функция исключений по доменам (команда site-exclusions):
- режим general: VPN используется для всех доменов, кроме списка исключений;
- режим selective: VPN используется только для доменов из списка исключений.

Основные команды:

    adguardvpn-cli site-exclusions -h
    adguardvpn-cli site-exclusions show
    adguardvpn-cli site-exclusions mode
    adguardvpn-cli site-exclusions add example.org
    adguardvpn-cli site-exclusions remove example.org

Эти команды управляют доменными исключениями, а не списком исполняемых файлов.

## Маршрутизация отдельных приложений

В официальном интерфейсе AdGuard VPN CLI не документирован механизм выбора приложений по исполняемому файлу или PID. Режим TUN прозрачно направляет трафик приложений по системным правилам маршрутизации; сам по себе он не предоставляет GUI для per-application routing.

Поэтому вкладка «Приложения» не должна выдавать доменные исключения за маршрутизацию процессов. Настоящая маршрутизация приложений в Linux потребует отдельного механизма на уровне ОС (например, policy routing с устойчивой идентификацией процессов/пользователей), а также согласованной обработки DNS, IPv4, IPv6, дочерних процессов и обновления правил при запуске/остановке VPN.

До реализации и проверки всех этих условий функция считается не реализованной. Нельзя показывать отметки приложений как действующие правила маршрутизации.

## Безопасность

- Не изменять системные маршруты и firewall без явного согласия пользователя.
- Не применять правила, если невозможно подтвердить корректный откат.
- Не утверждать, что split tunneling работает, пока не пройдены проверки маршрутов, DNS и IPv6.
